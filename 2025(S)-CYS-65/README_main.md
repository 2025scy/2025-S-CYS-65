## How to Run

1. Install Python 3 and VS Code.
2. Install the libraries:
   ```
   pip install pandas scikit-learn openpyxl notebook
   ```
3. Open a lab folder and run its file:
   ```
   python AI_Lab1.py
   python lab2.py
   jupyter notebook lab3.ipynb
   ```
